# 🗓️ Roadmap Android فقط (8 أسابيع)

## Week 1 — App Skeleton + Design System

**الهدف:** تعمل UI framework ثابت يخليك تبني باقي الشاشات بسرعة.

✅ Tasks

* Material3 theme + tokens (colors/typography/spacings)
* Components reusable:

  * `PrimaryCard`
  * `ActionTile`
  * `ListTile`
  * `SectionHeader`
  * `MoneyText`
* Navigation:

  * BottomBar + NavHost (5 tabs)
  * كل Tab له graph صغير (nested nav)
* State management:

  * ViewModels لكل tab
  * `collectAsStateWithLifecycle`

🎯 Deliverable

* App فيها الـ 5 tabs + شاشات placeholder + شكل عام قريب من الصور (حتى لو بيانات fake)

---

## Week 2 — Accounts Tab (زي الصورة الأولى)

**الهدف:** Accounts list UI + API integration + loading/error states.

✅ Tasks

* شاشة Accounts:

  * Header: “Accounts” + “Create new account +”
  * Account cards (primary + secondary)
  * Balance + masked account number
* Integration:

  * call `GET /accounts`
  * cache in memory (ViewModel)
* UX states:

  * Skeleton loading (shimmer أو placeholders)
  * Retry on error

🎯 Deliverable

* Accounts UI مطابق تقريبًا + بيانات من backend

* Cards tab جاهزة زي الصورة

## Week 8 — Polish + QA + Beta Readiness

**الهدف:** تجعل التجربة “Beta-ready” بدون bugs.

✅ Tasks

* UI polish:

  * padding consistency
  * typography alignment
  * RTL readiness (لو هتدعم عربي)
  * dark mode (اختياري)
* Performance:

  * avoid passing Activity/NavController/Vm as params (زي اللي اشتغلنا عليه)
  * stable state models (data class val)
* Error handling:

  * network errors
  * empty states
  * offline message بسيط
* Analytics (اختياري):

  * Firebase analytics events basic
* Release:

  * versioning
  * internal testing build

🎯 Deliverable

* APK/AAB Beta ready
